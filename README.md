# 张睿曦的个人主页与博客

基于 [Astro](https://astro.build/) + 定制版 [AstroPaper](https://github.com/satnaing/astro-paper) 主题，托管于 GitHub Pages。

- 线上地址：https://ruixizhang03.github.io
- 文章存放在 `src/content/posts/`（Markdown / MDX）
- 站点配置在 `astro-paper.config.ts`

## 本地开发

```bash
pnpm install
pnpm dev      # http://localhost:4321
pnpm build    # 类型检查 + 构建到 dist/
```
